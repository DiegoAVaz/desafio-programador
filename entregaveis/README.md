# Planilhas entregáveis

Esta pasta contém XLSX, CSV e JSON gerados pelo comando abaixo a partir dos PDFs em `exemplos/`:

```powershell
cd backend
npm.cmd run gerar:entregaveis
```

Os arquivos representam a transcrição atual do projeto no momento da geração. O `time-card-04` não recebe planilhas porque o layout não possui evidência suficiente para uma transcrição confiável; o arquivo `time-card-04.erro.txt` documenta o erro explícito retornado pelo processamento.
